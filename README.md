# Nutri Count

Plataforma de gestión nutricional inteligente para nutricionistas y pacientes.

## Ejecutar localmente

**Requisitos:** Node.js

1. Instalar dependencias:
   `npm install`
2. Configurar las variables de entorno en `.env` (ver [.env.example](.env.example))
3. Ejecutar la app:
   `npm run dev`
